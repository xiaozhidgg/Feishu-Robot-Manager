飞书应用怎么配

  1. 建应用：飞书开放平台 → 创建企业自建应用，名字随便起，图标可后补。
  2. 取凭证：「凭证与基础信息」页复制 App ID 与 App Secret，填到本页上面两栏。
  3. 开机器人：「添加应用能力」里勾选「机器人」。
  4. 配权限：「权限管理」里搜索「消息」，开通「获取与发送单聊、群组消息」与「接收群聊中 @ 机器人消息」。
  5. 收事件：「事件与回调」订阅方式选「长连接」，再添加事件「接收消息 im.message.receive_v1」。
  6. 发布：「版本管理与发布」创建版本并申请发布，管理员通过后，把机器人拉进群 @ 它提问。

本页其余字段（模型、接口地址、API Key、人设提示词）只决定它怎么回答，不用去飞书后台；改完点右上角「保存」写回机器人目录的 .env。
